# Серверная часть Alma

Прокси между сайтом и моделью ИИ. Ключ модели хранится только здесь,
в браузер он не попадает.

```
server/
├── generate.php          ← точка входа: POST /api/generate.php
├── config.example.php    ← образец настроек
├── config.php            ← ваши настройки (создать, в git не попадает)
├── .htaccess             ← запрет доступа к настройкам и логам
└── storage/              ← лимиты и журнал ошибок (создаётся сама)
    └── .htaccess
```

## Что нужно от хостинга

- PHP 7.4 или новее;
- расширение **cURL**;
- права на запись в папку `storage/`;
- желательно HTTPS (иначе браузер может блокировать запросы).

Обычный шаред-хостинг с PHP подходит. Отдельная база данных не нужна.

## Установка на server.ru (или другой хостинг)

1. Загрузите папку `server/` на хостинг, например в `public_html/api/`.
   Внутри должны оказаться `generate.php`, `.htaccess` и `storage/`.
2. Скопируйте `config.example.php` в `config.php` **на сервере**.
   Не загружайте `config.php` из репозитория — его там нет и быть не должно.
3. Заполните `config.php`:
   - `api_url` — адрес API выбранного сервиса;
   - `api_key` — ключ модели;
   - `model` — имя модели;
   - `allowed_origins` — адреса сайта. Для GitHub Pages это
     `https://qqquies.github.io`, после переезда — новый домен.
4. Проверьте, что `storage/` существует и доступна для записи
   (права `755` или `775`).
5. Откройте в браузере `https://ваш-домен/api/generate.php` методом GET —
   должен прийти ответ `{"error":"Нужен POST-запрос."}`. Это значит, что
   PHP работает.
6. Соберите сайт с адресом прокси:

   ```bash
   # .env.local в папке site/
   VITE_AI_ENDPOINT=https://ваш-домен/api/generate.php
   ```

   Затем `npm run build` и деплой. Без этой переменной сайт обращается
   к `/api/generate.php` на своём же домене.

## Проверка запросом

```bash
curl -X POST https://ваш-домен/api/generate.php \
  -H "Content-Type: application/json" \
  -d '{"subject":"Алгебра","grade":"8","topic":"Линейные уравнения","count":6,"difficulty":"mixed","verify":true}'
```

Ответ:

```json
{
  "items": [
    {
      "text": "Решите уравнение: 4x + 13 = 49.",
      "options": ["9", "4,5", "27", "18"],
      "correctIndex": 0,
      "explanation": "4x = 36, x = 9.",
      "level": "basic",
      "check": "ok"
    }
  ]
}
```

### Презентация

Тот же адрес, но в запросе есть `"kind": "presentation"`:

```bash
curl -X POST https://ваш-домен/api/generate.php \
  -H "Content-Type: application/json" \
  -d '{"kind":"presentation","subject":"Алгебра","grade":"8","topic":"Линейные уравнения","count":8}'
```

Ответ:

```json
{
  "slides": [
    { "title": "Линейные уравнения", "bullets": [], "note": "Титульный слайд." },
    { "title": "План занятия", "bullets": ["Повторение", "Новое правило"], "note": "..." }
  ]
}
```

Файл `.pptx` собирается уже в браузере учителя: сервер отдаёт только
текст слайдов. Поэтому презентацию можно править и сохранять без
повторного обращения к модели.

## Лимиты и безопасность

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `rate.global_per_day` | 300 | всего генераций в сутки на весь сайт |
| `rate.ip_per_day` | 30 | генераций в сутки с одного адреса |
| `timeout` | 60 | секунд ожидания ответа модели |

- Ключ лежит в `config.php`, доступ к файлу закрыт `.htaccess`.
- В `storage/` пишутся только счётчики и текст ошибок, без заданий.
- IP-адреса хранятся в виде хеша с солью из `config.php`.
- Если модель ответила мусором, прокси отбрасывает битые задания
  и возвращает только те, что прошли проверку формата.
- Учитель всё равно видит черновик и подтверждает ответы — ИИ не
  печатает работу без проверки.

## Если хостинг на Nginx

`.htaccess` не работает. Закройте файлы вручную:

```nginx
location ~ ^/api/(config\.php|storage/) {
    deny all;
}
```

## Смена модели

Достаточно поменять три строки в `config.php`:

```php
'api_url' => 'https://api.deepseek.com/chat/completions',
'api_key' => 'sk-...',
'model'   => 'deepseek-chat',
```

Подходит любой сервис с форматом запросов OpenAI. Если сервис не
поддерживает `response_format`, поставьте `'json_mode' => false` —
прокси всё равно вытащит JSON из ответа.
