# Alma

Цифровой школьный помощник для учеников и учителей. Ученику — интерактивные
уроки с проверками и итоговой работой; учителю — банк заданий, печать A4
и презентации к уроку.

Название происходит от латинского выражения *Alma Mater* («кормящая мать») —
традиционного обозначения места получения образования.

## Что уже работает

- Модуль «Специальная теория относительности»: 7 уроков, 3 интерактивные
  модели, квизы после уроков и итоговая работа с оценкой 2–5.
- Учительская: сначала выбор предмета, затем меню из двух инструментов —
  контрольные работы и презентации. 12 предметов и «Другой предмет»
  с иконками Lucide, популярные темы по классам.
- Банк заданий по физике: 7 тем и «Сборная работа», два варианта, бланк,
  ключ и пояснения, печать A4.
- Черновики работ по алгебре, русскому языку и любому другому предмету
  через ИИ с обязательной проверкой учителем.
- Презентации к уроку в чате с ИИ: учитель пишет тему, модель предлагает
  структуру слайдов, файл `.pptx` собирается и скачивается в браузере.
- Светлая и тёмная темы, выбор запоминается в браузере.

## Стек

- [Vite](https://vite.dev) + [React](https://react.dev)
- [React Router](https://reactrouter.com) — навигация
- [Lucide](https://lucide.dev) — иконки интерфейса (ISC)
- Canvas 2D — интерактивные симуляции
- Банк заданий — работает офлайн, ответы считаются формулами
- ИИ-черновики — через Cloudflare Pages Functions + Workers AI
  (`cloudflare/`), модель Llama 3.3 70B, ключ не попадает в браузер.
  PHP-вариант (`server/`) остаётся запасным для хостинга с PHP.
- [pptxgenjs](https://gitbrent.github.io/PptxGenJS/) — редактируемые
  презентации `.pptx`

## Команды

```bash
npm install       # установить зависимости
npm run dev       # сервер разработки → http://localhost:5173
npm run build     # production-сборка в папку dist
npm run lint      # проверка кода
npm run test:worker  # тесты серверной части ИИ
npm run deploy:pages # обновить ИИ на Cloudflare Pages
```

## Раздел для учителя

Вход начинается с вопроса «Какой предмет вы преподаёте?». Выбор запоминается
в браузере, но его всегда можно поменять кнопкой «Сменить предмет».

| Маршрут | Что открывается |
|---|---|
| `#/teacher` | выбор предмета |
| `#/teacher/:subjectId` | меню предмета: контрольные и презентации |
| `#/teacher/:subjectId/tests` | контрольные работы |
| `#/teacher/:subjectId/presentation` | чат с ИИ для презентаций |

Старый адрес `#/teacher/presentation` перенаправляет на презентации
по физике, чтобы прежние ссылки не ломались.

**Контрольные.** Физика собирается из авторского банка Alma; остальные
предметы и «другой предмет» — через черновик ИИ с обязательной проверкой
учителем. В разделе «Тема контрольной» показываются только темы выбранного
предмета и класса: у физики это скорость и плотность в 7 классе, закон Ома
в 8-м, законы Ньютона в 9-м, теория относительности в 9–11-м. Печать — A4
через диалог браузера, ключ и пояснения идут отдельными листами.

**Презентации.** Чат: реплики учителя — зелёные пузыри справа, ответы
Llama/ИИ — слева. Модель разбирает тему, класс и число слайдов из запроса,
показывает предупреждения, затем учитель проверяет и правит слайды
и скачивает редактируемый `.pptx`. Файл собирается локально через
`pptxgenjs`, поэтому готовую презентацию можно открыть в PowerPoint,
Keynote или «Р7-Офис».

В браузере сохраняются только последняя работа и последний черновик
презентации. Они привязаны к предмету из адреса: черновик по физике
не появится в алгебре.

### Почему Llama 3.3 70B

`@cf/meta/llama-3.3-70b-instruct-fp8-fast` работает через Cloudflare
Workers AI. Отдельный ключ не нужен, есть бесплатный дневной лимит,
а 70 миллиардов параметров хватает для русского текста и ответа в заданной
структуре JSON. Вариант `fp8-fast` заметно быстрее полной модели, поэтому
генерация обычно занимает 15–40 секунд. Модель остаётся автором черновика,
а не готовой работы: учитель проверяет формулировки, ответы и факты.

Подробное сравнение с другими моделями и все лицензии — в
[`docs/ИСТОЧНИКИ.md`](docs/ИСТОЧНИКИ.md).

Серверная часть описана в [`cloudflare/README.md`](cloudflare/README.md).
Основной адрес — Cloudflare Pages Functions + Workers AI: отдельный ключ
не нужен, бесплатный дневной запас. Адрес задаётся в `.env.production`:

```bash
VITE_AI_ENDPOINT=https://alma-ai-73x.pages.dev/api/generate
```

Дополнительно в `cloudflare/` лежит вариант Worker. Он может пригодиться,
если `workers.dev` доступен из вашей сети. Если позже понадобится хостинг
с PHP, остаётся вариант из [`server/README.md`](server/README.md).

## Структура

```
src/
├── components/   # переиспользуемые блоки (Layout, Quiz, блоки урока)
├── modules/      # образовательные модули
│   └── relativity/
│       ├── index.js          # данные модуля и список уроков
│       ├── lessons/          # страницы уроков
│       ├── quiz/             # вопросы квизов (данные)
│       └── *.jsx             # интерактивные симуляции
├── pages/        # маршруты: главная, уроки, учительская, о проекте
├── teacher/      # банк заданий, темы по классам, клиент ИИ, печать,
│                 # профиль учителя и сборка презентаций
└── lib/          # вспомогательные утилиты (цикл анимации, lastWork)

server/           # PHP-прокси к модели (запасной вариант, загружается отдельно)
cloudflare/       # ИИ на Cloudflare: Pages Functions + Workers AI
docs/             # материалы для жюри, источники, скриншоты
```

Новый модуль добавляется созданием папки в `src/modules/` и одной строки в
`src/modules/registry.js`.
