# ИИ-часть Alma на Cloudflare

Серверный посредник между сайтом и моделью. Он принимает запросы из браузера,
добавляет методический промпт, вызывает модель и проверяет ответ по формату.
Ключ модели (если он вообще нужен) остаётся на стороне Cloudflare и никогда
не попадает в браузер.

По умолчанию используется **Workers AI** — модель работает на стороне
Cloudflare. Отдельный ключ и оплата не нужны: бесплатный план даёт
10 000 Neurons в сутки. Этого хватает на несколько десятков небольших
работ или презентаций; точный расход виден в панели Cloudflare.

## Текущий адрес

Основной рабочий адрес — Cloudflare Pages Functions:

```text
https://alma-ai-73x.pages.dev/api/generate
```

Он прописан в `.env.production`:

```bash
VITE_AI_ENDPOINT=https://alma-ai-73x.pages.dev/api/generate
```

Проверка в браузере или через `curl.exe`:

```powershell
curl.exe -sS https://alma-ai-73x.pages.dev/api/generate
```

Должен прийти ответ:

```json
{"ok":true,"service":"alma-ai","backend":"workers-ai","model":"@cf/meta/llama-3.3-70b-instruct-fp8-fast"}
```

Проверка настоящей генерации:

```powershell
curl.exe -sS -X POST "https://alma-ai-73x.pages.dev/api/generate" `
  -H "Content-Type: application/json" `
  -d "{\"subject\":\"Алгебра\",\"grade\":\"8\",\"topic\":\"Линейные уравнения\",\"count\":5,\"difficulty\":\"mixed\"}"
```

Первый ответ может идти 20–60 секунд. Это нормально.

## Почему не `workers.dev`

Рядом лежит обычный Worker (`worker.js`, `wrangler.toml`). Он тоже
задеплоен, но в некоторых школьных сетях адреса `*.workers.dev`
не открываются по HTTPS. Поэтому сайт использует Pages-адрес, а Worker
остаётся запасным вариантом для другой сети.

## Как обновить ИИ-часть

Один раз войти в Cloudflare:

```powershell
npx wrangler login
```

После правок в `worker.js` или промптах:

```powershell
npm run test:worker
npm run deploy:pages
```

`deploy:pages` собирает Functions из `cloudflare/pages/` и публикует новую
версию на том же адресе `https://alma-ai-73x.pages.dev`.

Если нужно обновить и запасной Worker:

```powershell
npm run deploy:worker
```

## Как поменять модель

По умолчанию стоит `@cf/meta/llama-3.3-70b-instruct-fp8-fast` — бесплатная
модель с нормальным русским и приемлемой скоростью. В `cloudflare/pages/wrangler.toml`
можно добавить переменную:

```toml
[vars]
AI_MODEL = "@cf/meta/llama-3.3-70b-instruct-fp8-fast"
```

Другие бесплатные варианты: `@cf/mistralai/mistral-small-3.1-24b-instruct`,
`@cf/google/gemma-4-26b-a4b-it`. Некоторые модели требуют платного плана —
если ответ будет с ошибкой про billing, вернитесь к Llama 3.3 70B.

Для reasoning-моделей вроде Qwen можно добавить `reasoning_effort = "low"`,
но они заметно медленнее: 4 слайда могут генерироваться около минуты.

## Если позже появится ключ OpenRouter

Worker и Pages-функция умеют работать через OpenRouter. Это полезно, если
нужна более сильная платная модель или бесплатные модели OpenRouter.

1. Добавьте секрет `OPENROUTER_API_KEY`.
2. Добавьте переменную `OPENROUTER_MODEL` с именем модели, например
   `meta-llama/llama-3.3-70b-instruct:free`.
3. Перезапустите Worker или переdeploy-те Pages.

Код сам выберет OpenRouter, если ключ задан. Если ключа нет — останется
Workers AI. Ключ в браузер не попадает.

## Что важно понимать

- **Это не полноценная защита от злоупотребления.** CORS не даёт
  обращаться к генератору с чужого сайта через браузер, но прямой запрос
  из скрипта всё равно возможен. Основной ограничитель — дневной
  бесплатный запас Workers AI. Для настоящей школьной нагрузки нужен
  вход или Cloudflare Access.
- **Лимит в памяти** (20 запросов в час с одного IP) — грубый ограничитель,
  а не точный счётчик. Он сбрасывается при перезапуске экземпляра.
- **Модель — черновик.** Учитель всё равно проверяет каждое задание
  на экране «Проверка черновика» и каждый слайд на экране
  «Проверка презентации». Это не формальность: модель может ошибиться
  в арифметике, единицах или формулировке.
- **Ответ проверяется по формату.** Задания с выбором без четырёх разных
  вариантов или с `correctIndex` вне 0–3 отбрасываются. Задания с кратким
  ответом отбрасываются, если в них нет непустого `answer`. Если не осталось
  ни одного корректного задания, сайт покажет ошибку и предложит банк Alma.
  В одном черновике могут быть оба типа заданий.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `{"error":"В Worker не подключён Workers AI..."}` | Binding с именем `AI` в настройках проекта |
| `Модель не ответила вовремя` | Попробовать ещё раз; бесплатная модель иногда стоит в очереди |
| `Лимит бесплатных запросов...` | Дневной запас закончился; подождать до 00:00 UTC или подключить OpenRouter |
| `Этот сайт не имеет доступа...` | В `ALLOWED_ORIGINS` нет адреса сайта; добавьте нужный |
| Сайт пишет «Сервер генерации недоступен» | В `.env.production` неверный адрес или сборка сделана без него |
| `SSL/TLS` при открытии `workers.dev` | Использовать Pages-адрес `alma-ai-73x.pages.dev` |

## Файлы

```text
cloudflare/
├── worker.js                 ← общий код: промпты, проверка, вызов модели
├── worker.test.mjs           ← локальные тесты (node --test)
├── wrangler.toml             ← конфиг запасного Worker
├── README.md                 ← этот файл
└── pages/
    ├── wrangler.toml         ← конфиг Pages + binding AI
    ├── functions/api/generate.js ← точка входа Pages
    └── public/index.html     ← служебная страница
```

Тесты запускаются без Cloudflare и без ключа:

```bash
npm run test:worker
```
